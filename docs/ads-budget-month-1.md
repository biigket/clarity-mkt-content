# Ads Budget · Month 1 Test Phase

> **Status:** Approved · 29 May 2026
> **Phase:** 1 of 2 (Test → Scale)
> **Total:** 60,000 THB · Week 1-2

---

## Executive Summary

Month 1 = signal-gathering phase. Run **mixed-format creative** (video + static + carousel) across **TikTok + Meta** to identify top 2-3 winners by CPL + CTR. No scarcity, no discounts — pure brand-doctrine ads.

After Week 2 → concentrate budget on winners + Phase 2 scale plan.

## Video Budget · 36K · Platform Split

### Phase 1 · TikTok 50 / IG 30 / FB 20

```
┌──────────┬─────────┬─────┬──────────────────────────────────┐
│ Platform │ Amount  │ %   │ Persona reach                    │
├──────────┼─────────┼─────┼──────────────────────────────────┤
│ TikTok   │ 18,000  │ 50% │ A primary + B primary (~70% A+B) │
│ IG       │ 10,800  │ 30% │ A1 + C primary + B secondary     │
│ FB       │  7,200  │ 20% │ A2 + C secondary · retargeting   │
└──────────┴─────────┴─────┴──────────────────────────────────┘
```

**Rationale:**

| Platform | % | ทำไม |
|---|---|---|
| **TikTok** | 50% | CPM 30-50% ถูกกว่า Meta ใน TH aesthetic · Persona A+B = 70% · TikTok primary · cold-acquisition winner |
| **IG** | 30% | Persona C primary + A1 secondary · Reels growing · aesthetic premium fit · warm conversion |
| **FB** | 20% | Persona A2 (gov/state) + C secondary · pixel เก็บ retargeting pool · older skew |

### Per-Ad Allocation (6,000 THB ต่อ ad)

```
Each AD runs on all 3 platforms · 14 days:
  TikTok:  3,000 (50% · ~214/day)
  IG:      1,800 (30% · ~129/day)
  FB:      1,200 (20% · ~86/day)

→ ทุก platform ผ่าน minimum daily spend
→ Algorithm learning phase ผ่าน · ได้ signal ต่อ ad ต่อ platform
```

## Kill Criteria · Day 3-7

Per `ads/month-1-hook-bank.md`:

| Metric | Kill if |
|---|---|
| 3-sec view rate | < 40% |
| CTR (TikTok) | < 0.5% |
| CTR (Meta) | < 1% |
| CPL | > 80 THB Day 5+ |
| VTR 50% | < 15% |

→ Pause + reallocate budget ทันที (ไม่รอ end of week)

---

## Scale Criteria · Day 5-7

| Metric | Scale 2× if |
|---|---|
| CPL | ≤ 50 THB |
| CTR (Meta) | ≥ 1.5% |
| CTR (TikTok) | ≥ 0.8% |
| Save/share rate | > 2% |
| Comments quality | questions (not just emoji) |

→ ใช้ remaining budget เพิ่ม spend top 2-3 winners ใน Week 2

## Risks + Mitigations

| Risk | Severity | Mitigation |
|---|---|---|
| TikTok ad approval strict ใน aesthetic/medical | High | Pre-check ทุกคลิป · ห้าม before/after · ห้าม clinical claims · ห้าม brand machine names |
| Meta ad approval "อย." product | Medium | ใส่ disclaimer "ผลลัพธ์เฉพาะบุคคล" ทุกคลิป |
| FB feed clip 30-60s overlong | Low | Cut 15s variants สำหรับ FB story + reels placement |
| CPL > kill criteria Day 5 | Low | Auto-kill rule · reallocate ทันที |
| All 6 ads fail to differentiate | Low | Backup Hook Bank #4-#10 พร้อม swap |
| Algorithm learning phase incomplete | Low | Minimum spend per platform ผ่าน (TikTok 214/day · Meta 215/day) |
