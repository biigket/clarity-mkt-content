## Production Checklist

### Pre-production — CRITICAL
- [ ] **Patient consent ลายลักษณ์อักษร** — ใช้ template `assets/templates/patient-consent.md`
- [ ] Patient sign ระบุ usage type ชัดเจน

- [ ] Setup reference grid + headrest marker เพื่อ replicate angle
- [ ] Photos จาก archive ต้องมี timestamp + EXIF check

### Talent
- หมอ Big — เสื้อยืดสี soft + เสื้อแล็บเปิด (VO + intro/close on-cam)
- Patient — appear in 3-frame timelapse · no live interview

### Equipment
- กล้อง 4K + tripod (intro/close)
- Lavalier mic หมอ Big
- Reference photos Day 7/30/90 ต้อง bring on shoot

### Setup
- Mask identity ถ้า patient ขอ (blur ที่ patient ระบุ · ห้าม blur skin texture)
- Color grade: ห้าม retouch/filter/slim
- Visual treatment: subtle zoom on each frame · ห้าม dramatic transition
