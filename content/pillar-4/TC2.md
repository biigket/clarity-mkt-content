## Approved TTS Script

```
หมอชอบส่องไฟฉาย เพราะอะไร

ไฟฉาย คือเครื่องมือที่ราคาถูกที่สุดในห้องตรวจของผม แต่สำคัญมาก

ภายใต้แสงห้องตรวจปกติ หลุมสิวเห็นแค่ 40 เปอร์เซ็นเท่านั้น ที่เหลือซ่อนอยู่ใต้ผิว

พอผมส่องไฟฉายขนานกับผิว ทุกหลุมเล็กหลุมใหญ่ ขึ้นมาเห็นชัด เห็นรูปร่าง เห็นความลึก เห็นที่ตาเปล่ามองข้ามไป

บางครั้งตอนทำผมก็ฉายไฟไปด้วย เพื่อที่จะได้เก็บงานได้เนียบทุกหลุม เลือกเลเซอร์ และปรับพลังงานได้แม่นยำขึ้น

ที่ Clarity ผมส่องทุกเคส ทุกครั้ง ไม่มีข้อยกเว้น

ใครเคยเจอหมอที่ส่องไฟฉายตอน consult บ้าง คอมเม้นต์มาเลย
```

## Production Notes

- "ขนานกับผิว" = grazing light technique · macro shot ต้องเห็นเงาหลุมชัด
- "เก็บงานเนียบทุกหลุม" = workmanship signature · differentiator vs คลินิกที่ rush
- ห้าม name คลินิกคู่แข่ง · ใช้ "หมอที่ส่องไฟฉาย" framing เป็น signal
- Pair clip กับ PS1 (Trica3D scan) — TC2 = manual tool · PS1 = digital tool · ทั้งคู่ = "หมอ Big ดู skin ครบ"
- ไฟฉาย signature = brand prop · ปรากฏใน PE1, PS1, TC2 — consistent
