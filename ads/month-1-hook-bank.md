## 📊 Testing Strategy

| Phase | Hooks/clip | งบ/hook | Duration |
|-------|------------|---------|----------|
| **Week 1** | 3 (Top picks) | ~3K | 7 days |
| **Week 2** | Keep top 1 + add 2 fresh | ~5K | 7 days |
| **Week 3** | Scale winner 3x | ~10K | 7 days |
| **Week 4** | Refresh + introduce Tier 2 clips | — | 7 days |

## 🎯 Kill criteria (Day 3-7)

- 3-sec view rate < 40% → kill
- CTR < 0.5% (TikTok) / 1% (Meta) → kill
- CPL > 80฿ Day 5+ → kill
- VTR 50% < 15% → kill

## 🏆 Scale criteria (Day 5-7)

- CPL ≤ 50฿
- CTR ≥ 1.5% (Meta) / 0.8% (TikTok)
- Save/share rate > 2%
- Comments quality (questions, not just emoji)
- → scale budget 2x next week

## 🔄 How to use this file

1. **Designer/Editor:** ใช้ Top 3 per clip = 15 hook variants to produce
2. **Ad ops:** ทุก hook = ad set แยก · UTM tag ตามรหัส clip-hook (e.g., `am1-h1`, `am1-h4`)
3. **Refresh:** หา winner หลัง 7 days → กลับมาใช้ #4-#10 เป็น variants ใหม่
4. **Iterate:** ถ้า all 10 ใช้หมดแล้ว → run Phase 3 prompt again with learnings
